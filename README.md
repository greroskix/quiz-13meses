# 💝 Sistema de Avaliação Conjugal v13.0

Um projeto de front-end interativo desenvolvido como um presente personalizado de aniversário de namoro para celebrar a marca de **13 meses juntos**. O projeto consiste em um jogo de quiz dinâmico com 13 perguntas que relembram momentos marcantes, piadas internas e a história do casal.

---

## 🚀 Sobre o Projeto

A ideia principal foi transformar memórias em código, criando uma experiência interativa, visualmente romântica e divertida. 

*   **13 Perguntas Personalizadas:** Cada nível representa um mês de história.
*   **Visual Temático:** Interface responsiva, com paleta de cores e elementos visuais focados no tema.
*   **Interatividade Dinâmica:** Validação de respostas em tempo real e transições suaves entre as etapas.

## 🛠️ Tecnologias Utilizadas

O jogo foi construído puramente com tecnologias web nativas, focando em performance, simplicidade e sem a necessidade de frameworks pesados:

*   **HTML5:** Estruturação semântica das telas e do fluxo do quiz.
*   **CSS3:** Estilização customizada, design responsivo (adaptado para mobile e desktop) e animações suaves.
*   **JavaScript (ES6+):** Lógica do jogo, manipulação do DOM, controle dos estados das perguntas e validação das respostas.
